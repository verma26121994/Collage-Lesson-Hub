# Setup Guide

## Student App

1. Upload the student-app files to a GitHub repository.
2. Enable GitHub Pages.
3. Configure the public content endpoint.
4. Verify the PWA manifest and service worker.
5. Test the app on desktop and mobile.

## Teacher Dashboard

1. Create the required Google Sheet tabs.
2. Add the Apps Script backend.
3. Configure the spreadsheet and Drive folder.
4. Restrict the Apps Script web app to authorized users.
5. Test subject, unit, lecture, upload, and publish workflows.

## Important

Do not commit:
- private Google Sheet edit URLs
- teacher email addresses
- credentials
- private Apps Script deployment URLs
- API keys
- service-account files
